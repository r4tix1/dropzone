# Dropzone

A single-player 3D battle royale that runs in the browser. Drop onto the island, scavenge weapons, and outlast the bots while the storm closes in.

**Version 1.3.0**

## Features
- Solo, Duos (24 players), and Trios (36 players) modes, with bot teammates
- First- and third-person views (press `V`)
- Five weapons with ammo and reloading: pistol, rifle, shotgun, SMG, sniper
- 5-slot inventory with automatic pickup: carry several of the same gun, stack medkits and shield potions, press Q to drop an item
- Health, shield, and ammo pickups
- Hills, mountains, thick forests, open fields, and a shrinking storm
- Easy, Medium, and Hard bots
- Stacking damage numbers (white = health, blue = shield, yellow = headshot) and a shield-break effect
- Coins for eliminations, a chest shop, and a skin collection (progress is saved in your browser)
- Save codes: copy a code from the Save tab to move your progress to another device or browser

## Controls
| Key | Action |
|---|---|
| W A S D | Move |
| Mouse | Look |
| Left click / Space | Shoot |
| Right click | Zoom |
| R | Reload |
| 1 - 5 | Select inventory slot |
| Q | Drop the selected item |
| V | First / third person |
| J | Help, skins, and shop (pauses) |
| Arrow keys | Turn and look if mouse look doesn't work |

## Run locally
Open `index.html` in a browser. It loads three.js from a CDN, so you need an internet connection.

## Deploy with GitHub Pages
Push the repo, then go to Settings > Pages > Deploy from branch > `main` / root.
